# Screening (Phase 1 + Phase 2)

Title/abstract and full-text screening for the scoping review (Pub. 1), including the parallel human/AI screening approach.

## Contents

- `screening_prompt.md` — prompt used for AI-assisted screening
- `zotero_export_300.csv` — bibliographic export of the 300 deduplicated records
- `human_screening.xlsx` — human screening decisions (Phase 1, title/abstract; N = 295)
- `ai_screening.xlsx` — AI screening decisions (Phase 1, title/abstract; N = 295)
- `full_text_screening_log.xlsx` — full-text screening decisions (Phase 2; 158 forwarded records)
